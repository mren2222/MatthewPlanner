# Matthew Planner

Local-first Windows planner: flexible tasks by day and duration, exact appointments separately, AI changes previewed before approval.

Implementation in progress. See docs/ARCHITECTURE.md and docs/TASKS.md.

Node 22+ and pnpm required. Run `pnpm install`, `pnpm dev`, `pnpm test`, `pnpm typecheck`, `pnpm build`, `pnpm package`. Packaging produces a Windows app under release/win-unpacked.

No credentials are required to use local planning. Configure optional OpenAI and iCloud in Settings. Never add secrets to Git.
